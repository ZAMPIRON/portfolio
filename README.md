# Portfolio

Site de uma página em HTML/CSS/JS puro. Para ver, abra o `index.html` no navegador.

Enquanto uma imagem não existir, o site mostra um quadro listrado com o caminho esperado do arquivo.

## Imagens: onde colocar e qual nome dar

Use sempre **.jpg** e nomes **exatamente** como abaixo (minúsculas, com hífen).

| Arquivo | O que é | Status |
|---|---|---|
| `images/profile.jpg` | Sua foto (quadrada fica melhor) | falta |
| `images/frequencyon/screen-1..3.jpg` | Telas do sistema | ✅ |
| `images/frequencyon/totem.jpg` | Foto do totem de verdade (descomente a linha no HTML) | falta |
| `images/certificates/*.jpg` | CS50, Python, SQL, Excel, MySQL | ✅ |
| `images/childhood/champion.jpg` | Você criança sendo campeão | ✅ |
| `images/childhood/music.jpg` | Você criança tocando | falta |
| `images/music.jpg` | Sua foto tocando hoje | ✅ |
| `images/soccer.jpg` | Sua foto jogando futebol (vertical fica melhor) | falta |
| `images/community/natal-solidario.jpg` | Natal Solidário | falta |
| `images/community/jiu-jitsu.jpg` | Jiu-jitsu | falta |
| `images/community/tennis.jpg` | Tênis | falta |
| `docs/arrangement.pdf` | Arranjo da audição (PDF) | falta |

Certificado em PDF? Tire um print dele e salve como .jpg.

## O que falta editar no `index.html`

- **Vídeos**: suba no YouTube como "Não listado" e cole só o ID em `data-youtube=""`
  (FrequencyON e Music). Ex.: `https://youtu.be/abc123XYZ` vira `data-youtube="abc123XYZ"`.
- **E-mail**: troque `SEU-EMAIL@exemplo.com` (aparece 2 vezes).

## Antes de publicar

- Não mostre rosto nem nome de outros alunos sem permissão (desfoque, se precisar).
- Depois de publicar, abra o link numa aba anônima para conferir.
