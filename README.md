# Portfolio

Site de uma página em HTML/CSS/JS puro. Para ver, abra o `index.html` no navegador.

Enquanto uma imagem não existir, o site mostra um quadro listrado com o caminho esperado do arquivo.

## Imagens: onde colocar e qual nome dar

Use sempre **.jpg** e nomes **exatamente** como abaixo (minúsculas, com hífen).

| Arquivo | O que é |
|---|---|
| `images/profile.jpg` | Sua foto (quadrada fica melhor) |
| `images/frequencyon/totem.jpg` | Foto do totem (aparece grande) |
| `images/frequencyon/screen-1.jpg` | Tela do sistema |
| `images/frequencyon/screen-2.jpg` | Outra tela do sistema |
| `images/buddy-matcher/screenshot-1.jpg` | Print do Buddy Matcher |
| `images/buddy-matcher/screenshot-2.jpg` | Outro print |
| `images/certificates/cs50.jpg` | Certificado CS50x |
| `images/certificates/python.jpg` | Certificado Python |
| `images/certificates/sql.jpg` | Certificado SQL |
| `images/certificates/excel.jpg` | Certificado Excel |
| `images/soccer.jpg` | Sua foto jogando futebol (vertical fica melhor) |
| `images/community/natal-solidario.jpg` | Natal Solidário |
| `images/community/jiu-jitsu.jpg` | Jiu-jitsu |
| `images/community/tennis.jpg` | Tênis |
| `docs/arrangement.pdf` | Arranjo da audição (PDF) |

Certificado em PDF? Tire um print dele e salve como .jpg.

## O que editar no `index.html`

- **Vídeos**: suba no YouTube como "Não listado" e cole só o ID em `data-youtube=""`.
  Ex.: `https://youtu.be/abc123XYZ` vira `data-youtube="abc123XYZ"`.
- **GitHub**: troque os `href="#"` dos botões "View code on GitHub".
- **E-mail**: troque `SEU-EMAIL@exemplo.com` (aparece 2 vezes).
- **Textos**: revise as tecnologias e descrições do FrequencyON e do Buddy Matcher.

## Antes de publicar

- Não mostre rosto nem nome de outros alunos sem permissão (desfoque, se precisar).
- Depois de publicar, abra o link numa aba anônima para conferir.
